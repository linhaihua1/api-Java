# 03 - 配置指南

## 一、配置体系总览

框架采用 **三层配置优先级**：

```
环境变量 (AMSAPI_*)  ← 最高优先级（CI/CD 用）
       ↓
config/conf.ini      ← 项目级配置（日常用）
       ↓
代码默认值           ← 兜底
```

所有可变数据 **禁止硬编码**，必须通过这三层之一提供。

> **默认值来源**：第三层「代码默认值」全部集中于 `com.amsapi.common.Constants` 类（如 `DEFAULT_TIMEOUT_SEC=10`、`DEFAULT_SYSTEM="default"`、`DEFAULT_REPORT_TYPE="allure"` 等），框架中无散落的硬编码字面量。如需调整默认值，修改 Constants.java 重新编译即可。

## 二、全局配置 conf.ini

文件位置：`config/conf.ini`

### 2.1 [env] — 环境信息

```ini
[env]
env = test                    # 环境标识，仅用于日志展示
base_url =                    # 主域名（留空则使用系统档案中的地址）
system = default              # 系统适配档案名（对应 config/systems/<名>.ini）
```

### 2.2 [run] — 运行开关

```ini
[run]
data_source = yaml            # 数据源：excel / yaml / mysql / all
sheet_name = test_case_list   # Excel sheet 名（data_source=excel 时有效）
write_back = true             # 是否回写执行结果到 Excel
timeout = 10                  # 请求超时（秒）
verify = false                # 是否验证 SSL 证书
smoke = false                 # 是否只执行冒烟用例
tags = smoke                  # 冒烟标签（逗号分隔）
```

### 2.3 [db] — 数据库（可选）

```ini
[db]
host =                        # MySQL 地址
user =                        # 用户名
password =                    # 密码
database =                    # 数据库名
port = 3306                   # 端口
charset = utf8                # 字符集
web =                         # 环境标识
environment =                 # 环境名
```

### 2.4 [report] — 报告

```ini
[report]
report_type = allure          # 报告类型：allure / html / both / none
title = 接口自动化测试        # 报告标题
project = amsapi-auto         # 项目名
html_name = report.html       # HTML 报告文件名
max_attach_len = 20000        # Allure 附件最大长度
```

### 2.5 [log] — 日志

```ini
[log]
level = DEBUG                 # 日志级别：DEBUG / INFO / WARN / ERROR
console_level = DEBUG         # 控制台级别
file_name_format = %Y_%m_%d   # 日志文件名格式（按天）
root_name = amsapi            # 日志根名称
```

### 2.6 [auth] — OAuth2 配置

```ini
[auth]
refresh_ahead = 60            # 令牌到期前多少秒提前刷新
token_timeout = 10            # 取令牌请求超时（秒）
token_verify = false          # 取令牌是否验证 SSL
```

### 2.7 [ci] — CI 检测

```ini
[ci]
detect_env_vars = JENKINS_URL,JENKINS_HOME,GITLAB_CI,BUILD_NUMBER
```

## 三、环境变量（AMSAPI_*）

所有配置项均可通过 `AMSAPI_` 前缀的环境变量覆盖，适合 CI/CD 流水线注入。

### 常用环境变量

| 环境变量 | 覆盖配置 | 示例 |
|---|---|---|
| `AMSAPI_BASE_URL` | `[env] base_url` | `http://127.0.0.1:8080` |
| `AMSAPI_SYSTEM` | `[env] system` | `mall` |
| `AMSAPI_DATA_SOURCE` | `[run] data_source` | `yaml` |
| `AMSAPI_TIMEOUT` | `[run] timeout` | `30` |
| `AMSAPI_SMOKE` | `[run] smoke` | `true` |
| `AMSAPI_TAGS` | `[run] tags` | `smoke,core` |
| `AMSAPI_REPORT_TYPE` | `[report] report_type` | `allure` |
| `AMSAPI_DB_HOST` | `[db] host` | `10.0.0.1` |
| `AMSAPI_DB_USER` | `[db] user` | `tester` |
| `AMSAPI_DB_PASSWORD` | `[db] password` | `xxx` |
| `AMSAPI_DB_NAME` | `[db] database` | `test_db` |
| `AMSAPI_LOG_LEVEL` | `[log] level` | `INFO` |

### CI 示例

```bash
# Jenkins Pipeline 中
AMSAPI_BASE_URL=http://test-server:8080 \
AMSAPI_SYSTEM=mall \
AMSAPI_DATA_SOURCE=yaml \
AMSAPI_SMOKE=true \
mvn test -Dtest=TestYamlDriver
```

## 四、系统适配档案

文件位置：`config/systems/<名称>.ini`

通过 `AMSAPI_SYSTEM=<名称>` 或 `conf.ini` 的 `[env] system` 指定。

### 4.1 档案结构

```ini
[system]
name = 商城 / 购物
description = JWT 认证 + 网关多域名 + success 风格响应

[env]
base_url = http://gateway.mall.com
timeout = 10
verify = false
encoding =                  # 留空=自动探测；指定如 GBK
content_type = application/json
response_format = auto      # auto / json / xml / text

[hosts]
gateway = http://gateway.mall.com
user = http://user-service.mall.com
order = http://order-service.mall.com

[headers]
Content-Type = application/json
X-Client = amsapi-auto

[response]
style = success             # 判定风格（见 06-系统适配指南）
http_ok = 200,201,204

[auth]
type = bearer               # 认证类型
token = ${token}            # 支持 ${var} 占位符
header = Authorization
prefix = Bearer

[hooks]
before_request =            # 请求前钩子
after_response =            # 响应后钩子
```

### 4.2 切换系统

```bash
# 方式1：环境变量
AMSAPI_SYSTEM=mall mvn test

# 方式2：修改 conf.ini
[env]
system = mall
```

### 4.3 查看可用档案

档案列表 = `config/systems/` 目录下所有 `.ini` 文件（不含扩展名）。

## 五、日志配置

日志输出到两个地方：
1. **控制台** — 实时查看
2. **文件** — `log/` 目录下按天命名（如 `2026_10_01.log`）

日志格式：
```
2026-10-01 14:30:00 | INFO  | com.amsapi.api.BaseApi:120 | 【请求】GET http://...
```

## 六、路径配置

所有路径以项目根目录（`java/`）为基准：

| 配置项 | 默认值 | 环境变量 |
|---|---|---|
| 项目根 | `user.dir` | `AMSAPI_BASE_DIR` |
| 配置目录 | `<根>/config` | `AMSAPI_CONFIG_DIR` |
| 数据目录 | `<根>/data` | `AMSAPI_DATA_DIR` |
| 日志目录 | `<根>/log` | `AMSAPI_LOG_DIR` |
| 报告目录 | `<根>/report` | `AMSAPI_REPORT_DIR` |
