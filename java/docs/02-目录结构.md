## 二、核心文件详解

### 2.1 Constants.java — 全局常量中心

**职责**：框架唯一常量来源，集中存放所有「魔法值」，实现零硬编码。

**设计原则**：
1. 所有协议级字面量必须在此声明，禁止在业务代码中散落
2. 业务可配置项走 `Settings` / `SystemProfile`，此处只放不变常量
3. 常量命名全大写下划线，语义清晰

**常量分组**：

| 分组 | 示例常量 | 说明 |
|---|---|---|
| 编码 | `ENC_UTF8`、`ENC_ISO_8859_1` | 字符集名称 |
| HTTP 协议 | `CT_JSON`、`HDR_CONTENT_TYPE`、`M_GET`、`DEFAULT_HTTP_OK` | Content-Type、请求头、方法、成功状态码 |
| 时间/缓冲 | `MS_PER_SECOND`、`DEFAULT_TIMEOUT_SEC`、`DEFAULT_BUFFER_SIZE` | 毫秒换算、默认超时、缓冲区大小 |
| 默认值 | `DEFAULT_ENV`、`DEFAULT_SYSTEM`、`DEFAULT_REPORT_TYPE`、`DEFAULT_TAGS` | 环境、系统、报告、标签等默认值 |
| 响应判定风格 | `STYLE_STATUS`、`STYLE_CODE`、`STYLE_SUCCESS`、`STYLE_ERRNO`、`STYLE_RETCODE`、`STYLE_RAW` | 6 种判定风格名 |
| 数据源 | `DS_EXCEL`、`DS_YAML`、`DS_MYSQL`、`DS_ALL` | 数据源名称 |
| 用例字段名 | `FIELD_ID`、`FIELD_URL`、`FIELD_METHOD`、`FIELD_EXPECTS` 等 | 用例 Map 的键名，避免散落硬编码 |
| 响应结构字段 | `RES_CODE`、`RES_BODY`、`RES_ELAPSED` 等 | 统一响应结构的键名 |
| 认证 | `DEFAULT_TOKEN_TIMEOUT`、`DEFAULT_REFRESH_AHEAD` | OAuth2 令牌超时与提前刷新 |
| 正则 | `PATTERN_VAR` | `${var}` 占位符匹配 |

> 新增常量时，只需在此类添加 `public static final` 字段，全框架自动共享。

### 2.2 Settings.java — 配置中心

**职责**：全局唯一配置入口，管理所有可配置项。

**关键内部类**：
| 内部类 | 对应 conf.ini 段 | 管理内容 |
|---|---|---|
| `RunConfig` | `[env]` `[run]` | 数据源、超时、地址、冒烟开关 |
| `DB_CONFIG` | `[db]` | MySQL 连接信息 |
| `ReportConfig` | `[report]` | 报告标题、文件名 |
| `LogConfig` | `[log]` | 日志级别、格式 |
| `AuthConfig` | `[auth]` | OAuth2 令牌刷新配置 |
| `CIConfig` | `[ci]` | CI 环境检测变量 |

**静态初始化顺序**：
1. 计算路径常量（`BASE_DIR` → `CONFIG_DIR` → `LOG_DIR` 等）
2. 加载 `conf.ini` 覆盖默认值
3. 加载环境变量 `AMSAPI_*` 最高优先级覆盖

### 2.3 Base.java — 参数化核心

**职责**：处理用例中的动态参数。

| 方法 | 说明 |
|---|---|
| `find(data)` | 正则查找所有 `${var}` 占位符 |
| `replace(data)` | 把 `${var}` 替换为 GlobalVar 中的值 |
| `parseRelation(path, data)` | 按 `a.b.c` 路径从嵌套对象取值 |
| `parseExpression(expr, data)` | 解析 `name=body.data.ticket` → (name, value) |
| `safeLoads(text, default)` | 安全 JSON 解析（不执行代码） |
| `xmlToDict(text)` | XML 转 Map |
| `dictToXml(data, root)` | Map 转 XML |

### 2.4 BaseApi.java — 接口基类

**职责**：所有接口对象的父类，提供 8 项统一能力。

| 能力 | 方法 | 说明 |
|---|---|---|
| URL 组装 | `fullUrl()` | 相对路径拼主域名、支持域名别名 |
| 参数化 | `resolve()` | 请求前替换 `${var}` |
| 认证 | `applyAuth()` | 按档案自动附加令牌 |
| 钩子 | `applyBeforeHooks()` / `applyAfterHooks()` | 签名/时间戳/解密 |
| 请求 | `request()` | 统一 HTTP 请求入口 |
| 关联 | `extract()` | 响应字段写入 GlobalVar |
| 断言 | `checkExpects()` | 21 种算子调度 |
| 生命周期 | `runCase()` | setup → 请求 → teardown |

### 2.5 SystemProfile.java — 系统适配档案

**职责**：加载 `config/systems/*.ini`，把系统差异收敛为配置。

**解析内容**：
| INI 段 | Java 处理 |
|---|---|
| `[system]` | 系统名称、描述 |
| `[env]` | 主域名、超时、编码、报文格式 |
| `[hosts]` | 多服务域名别名映射 |
| `[headers]` | 公共请求头（保留大小写） |
| `[cookies]` | 公共 Cookie |
| `[response]` | 成功判定规则（→ ResponseSpec） |
| `[auth]` | 认证配置（→ AuthFactory） |
| `[hooks]` | 钩子声明（→ HookRegistry） |

### 2.6 Asserts.java — 断言引擎

**21 种算子**：equals, not_equals, contains, not_contains, startswith, endswith, regex, type, exists, not_exists, in, not_in, gt, ge, lt, le, length, empty, not_empty, elapsed, schema

**调度入口**：`runOp(name, response, path, value, msg)`

### 2.7 RequestSend.java — HTTP 封装

**统一返回结构**：
```java
{
    "code":    200,           // HTTP 状态码
    "body":    {...},         // 响应体（Map/List/String）
    "cookies": {...},         // 响应 Cookie
    "headers": {...},         // 响应头
    "elapsed": 123.45,        // 耗时（毫秒）
    "url":     "最终地址",
    "method":  "GET"
}
```

**关键能力**：
- 自动判定参数挂载位置（GET → query，POST + JSON → body）
- 支持 XML/JSON/Form/Text 多种 Content-Type
- 响应编码自动探测
